Each train no. is counted separately — 19337(1),20983(3,6) = 2 trains. A Term → Orig row counts its arriving train as terminating and its departing train as originating. On each PF a train no. is counted once even if it is in several rows (e.g. different days). Station total = sum of the PF rows. If a train no. is on more than one PF, or is both terminating and originating, a Unique train nos. row is added with the reason. With a day selected, only trains running that day are counted. Rows with errors (see Checks) are not counted.

Store charts in Google Drive

Charts are saved in your own Google Drive, folder PF Berthing Charts: current data, a chart picture, a copy of every save, and a Change log Google Sheet. One-time setup (5 minutes):
1. Open script.google.com → New project → paste the code from drive/Code.gs → change KEY to your own secret → Save.
2. Deploy → New deployment → Web app → Execute as Me → Who has access Anyone → Deploy → Authorize → copy the Web app URL.
3. Paste the URL and the same KEY below. The key is kept only in this browser — use Disconnect on a shared PC.
